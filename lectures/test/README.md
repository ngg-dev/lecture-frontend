# Тестовая лекция: от HTML до пикселя

Проверочная лекция в монорепозитории: проверяем формат «дека в вебе» и автодеплой на GitHub Pages.

## Чему учит

- Что происходит с документом после того, как браузер получил HTML: разбор, DOM, CSSOM, дерево отрисовки, layout, paint.
- Почему изменение одного атрибута иногда перерисовывает весь экран, а иногда — один пиксель.
- Как событие доходит от клика до обработчика, и почему `innerHTML` в цикле — плохая идея.

## Запуск

Сборки нет, файл самодостаточный. Открыть напрямую или поднять статику:

```bash
cd lectures/test
python3 -m http.server 8000
# http://localhost:8000
```

В деке: `→` / `пробел` — вперёд, `←` — назад, `Home` / `End` — начало и конец.
Номер слайда виден в адресе (`#5`) — ссылку на конкретный слайд можно отправить студентам.

## Упражнение

1. Открыть DevTools → Elements и найти узел, который добавляет кнопка на слайде 3.
2. В Performance записать взаимодействие и найти момент, когда браузер пересчитывает layout.
3. Переписать пример слайда 5 так, чтобы ввод не перерисовывал список на каждый символ.
